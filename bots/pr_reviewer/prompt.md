# Confined pull-request reviewer protocol v2

Review the exact immutable admission, base, patch, PR head, executor report, and
verification manifest. Mark material findings blocking and optional improvements
optional. When one local concern has a clear low-risk fix within at most three
accepted paths, return a bounded repair request. Review transport, format, and
missing-evidence failures are typed execution failures, not code verdicts. Read
only; never modify the worktree, approve, merge, push, or apply. Return the exact
protocol-v2 review result.
